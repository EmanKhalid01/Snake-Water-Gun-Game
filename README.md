# 🐍💧🔫 Snake Water Gun Game
Welcome to the ultimate Snake 🐍 vs Water 💧 vs Gun 🔫 battle!
A fun command-line game built with Python where you compete against the computer.

# 🎮 How the Game Works
The rules are simple (but deadly 😈):
🐍 Snake drinks Water → Snake wins
💧 Water rusts Gun → Water wins
🔫 Gun kills Snake → Gun wins

# 🚀 Features
✨ Random computer choices
🎯 Score tracking system
🔁 Unlimited rounds
❌ Input validation (no cheating allowed 😤)
🛑 Quit anytime with 'q'
😄 Fun emojis & interactive gameplay

# 🕹️ How to Play
Run the Python file:  python main.py
Enter your move:
s → Snake 🐍
w → Water 💧
g → Gun 🔫
q → Quit game
Try to beat the computer and get the highest score!

# 🧠 Game Logic (Behind the Scenes)

rules = {
